Before the lab, please complete the following (requires a restart):

1. Install WSL and Ubuntu
   - Open PowerShell:
     Press the Windows key, type PowerShell, right-click Windows PowerShell, and select Run as Administrator.

   - Run:
     wsl --install

   - Restart your computer when prompted.

2. Finish setting up Ubuntu
   - After restarting, a terminal window may open automatically and finish installing Ubuntu. If it does, skip to the username prompt below.

   - If no window opens:
     Press the Windows key, type Ubuntu, and select the Ubuntu app.
     You can also open PowerShell and run:
     wsl

   - Wait for the installation to finish. This can take a few minutes.

   - When prompted with:
     Enter new UNIX username

     Type a username using lowercase letters and no spaces, then press Enter.

   - When prompted with:
     New password

     Type a password and press Enter.
     Nothing will appear while typing. This is normal.

   - Re-enter the password when prompted and press Enter.

   - Setup is complete when the prompt looks similar to:
     username@COMPUTERNAME:~$

   - Save this password. You will need it during the lab.

3. Install Docker Desktop (if not already installed)
   - Open a web browser and go to:
     https://www.docker.com/products/docker-desktop/

   - Select Download for Windows and choose the version appropriate for your computer.

   - Run the installer.

   - When prompted, leave:
     Use WSL 2 instead of Hyper-V
     checked.

   - Restart or sign out if prompted.

4. Verify Docker Desktop
   - Open Docker Desktop.

   - Accept the terms.

   - Sign-in is optional.

   - Open:
     Settings > General

   - Ensure:
     Use the WSL 2 based engine
     is enabled.

5. Verify WSL Version
   - Open PowerShell and run:
     wsl --list --verbose

   - Confirm that Ubuntu shows:
     VERSION 2

If any step fails, especially with a virtualization error, please let me know before the lab.
